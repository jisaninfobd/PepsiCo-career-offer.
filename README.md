# PepsiCo Career Landing Page

A lightweight, responsive career-information landing page suitable for GitHub + Vercel.

## Compliance choices

This page intentionally:
- does not claim a particular PepsiCo job is currently available;
- does not claim the visitor has an interview scheduled;
- does not promise an interview;
- does not make hourly-wage claims;
- directs visitors to the official PepsiCo careers site for current listings and application details;
- states that the page is not affiliated with or endorsed by PepsiCo.

## Deploy to GitHub

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and this `README.md`.
3. Commit the files.

## Deploy to Vercel

1. Sign in to Vercel.
2. Select **Add New → Project**.
3. Import the GitHub repository.
4. No build command is required.
5. Deploy.

The page is plain HTML/CSS, so Vercel can serve it directly.
